# MidnightClips

Запись игровых клипов для Windows — как Medal и ShadowPlay, в жёлто-чёрном стиле Persona 4.

Программа всё время держит в памяти последние секунды экрана. Случилось что-то стоящее —
нажимаете **Alt+F10**, и последние 60 секунд сохраняются в mp4. Ничего перекодировать не нужно,
поэтому клип готов через пару секунд.

## Что умеет

- **Буфер повтора** — от 15 секунд до 30 минут, сохранение по горячей клавише.
- **Обычная запись** — **Alt+F9** начать и остановить.
- **Звук компьютера** и, по желанию, **микрофон**.
- **Кодирование видеокартой** (NVIDIA, AMD, Intel) — выбирается само; если не вышло, пишет процессором.
- **Галерея клипов** — превью, папки по играм, поиск, переименование, удаление в корзину,
  «Скопировать» для вставки в Discord через Ctrl+V.
- **Просмотр и обрезка** прямо в окне: два ползунка «начало — конец».
- **Сжатие под Discord** — клип ужимается до заданного размера (по умолчанию 10 МБ).
- **Отправка в Discord** одной кнопкой через вебхук канала.
- **Свои звуки и громкость** сигналов (wav, mp3, ogg…).
- **Автообновление** — при запуске сама ставит свежую версию из Releases.
- Сидит в трее, может запускаться вместе с Windows, подаёт сигнал и показывает уведомление при сохранении.

## Как получить exe

**Через GitHub (без установки чего-либо):** залейте эту папку в репозиторий — GitHub Actions
сам соберёт `MidnightClips-win64.zip` и выложит в Releases при каждом изменении в ветке `main`.

**На своём компьютере:** установите Python 3.12, запустите `build.bat`.
Готовая программа появится в `dist\MidnightClips\`. ffmpeg скачается сам.

**Без сборки:** положите `ffmpeg.exe` в эту папку и запустите `run.bat`.

Нужны Windows 10/11 и WebView2 (в Windows 11 есть сразу, в Windows 10 обычно тоже).

## Если что-то не так

- **Чёрный экран в клипе** — Настройки → Способ захвата → попробуйте другой.
  Игры в «эксклюзивном полноэкранном» режиме лучше переключить в «окно без рамки».
- **Горячая клавиша не срабатывает** — в настройках будет пометка «сочетание занято»:
  Alt+F10 по умолчанию использует и ShadowPlay. Назначьте другое.
- **Звук отстаёт или спешит** — Настройки → Звук → Сдвиг звука.
- **Захват не запускается** — Настройки → Журнал: там видно, что ответил ffmpeg.

## Устройство

| Файл | Что делает |
| --- | --- |
| `main.py` | окно, трей, связь интерфейса с программой |
| `midnightclips/recorder.py` | буфер повтора и запись (ffmpeg) |
| `midnightclips/audio.py` | звук компьютера (WASAPI loopback) |
| `midnightclips/hotkeys.py` | глобальные горячие клавиши |
| `midnightclips/library.py` | галерея: список, превью, переименование |
| `ui/` | интерфейс (HTML/CSS/JS) |
| `tests/test_pipeline.py` | проверка склейки клипов на тестовой картинке |

Оформление можно править, открыв `ui/index.html` прямо в браузере — включится демо-режим.
